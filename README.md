# BookExchange Romania (SchimbDeCartiRomania)

A self-hosted, community-driven physical book exchange platform built for Romania.

## Evolution

- **v1.0-university**: Legacy implementation built with Node.js, Express, and Vue during university studies. (Accessible via git tag `v1.0-university`).
- **v2.0-production (Current)**: Complete rewrite focusing on production readiness, infrastructure reliability, and DevOps best practices.
  - **Backend**: Python (FastAPI), SQLAlchemy, PostgreSQL
  - **Frontend**: Vue.js
  - **Infrastructure**: Docker, Docker Compose, Raspberry Pi 4 self-hosting, Automated Off-site Backups, CI/CD with GitHub Actions.

## Status

Project under active rewrite and scaffolding.
